## 🔭 Overview

This repository contains the source code for the visual interface of the JARVIS AI. It is designed to run in a web browser and provides an interactive user experience, simulating how a driver might interact with an onboard AI assistant.

---

## 🌟 Features

* **🤖 Interactive Chatbot**: A dedicated interface (found in `chatbot/`) for user-AI communication.
* **🎨 Modern UI/UX**: Custom styling using `style.css` and organized assets in `css/`.
* **⏳ Dynamic Preloader**: A smooth loading animation located in `preloader/` to enhance user experience.
* **📱 Responsive Design**: Optimized for different screen sizes.
* **🏎️ Tata Branding**: Integration of official Tata imagery (`Tata-Logo.png`, `TataXJarvis.png`).

---

## 🛠 Tech Stack

* **Structure**: HTML5 (`index.html`, `html/`)
* **Styling**: CSS3 (`style.css`, `css/`)
* **Logic & Interactivity**: JavaScript (`script.js`, `js/`)
* **Assets**: PNG Images

## 📥 Installation & Usage

Since this is a static web project, no complex installation or backend server is required.

### Option 1: Run Locally
1.  **Clone the repository**
    ```bash
    git clone [https://github.com/AbhishekSharma-9/JARVIS-Car-AI.git](https://github.com/AbhishekSharma-9/JARVIS-Car-AI.git)
    cd JARVIS-Car-AI
    ```

2.  **Launch the Dashboard**
    * Simply double-click the `index.html` file to open it in your default web browser (Chrome, Firefox, Edge, etc.).

### Option 2: Live Server (Recommended for Development)
If you are using VS Code:
1.  Install the **Live Server** extension.
2.  Right-click `index.html` and select **"Open with Live Server"**.
